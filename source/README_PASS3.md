# AetherOS Rev:F — Pass 3
Pass 3 integrates the runtime graph, recovery watchdog, adaptive governor, and live Wi-Fi gateway transport.
The DSi remains a classical host: quantum execution is local simulation or routed to an external gateway.
5G, satellite, Bluetooth, and SDR require corresponding external gateway hardware.
No module reports an external capability as physically present until a real transport/discovery layer confirms it.
