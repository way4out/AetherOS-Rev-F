AETHERMOD YHWH BIBLIO CODEX DATASET
=================================
This is the offline text-corpus gateway for the Codex reader.
The binary contains the book index and navigation shell; a complete public-domain
or licensed corpus may be placed here or in this directory without changing the
application. The reader never requires a network connection.

CORPUS CONTRACT
---------------
The Codex reader is designed for a public-domain or properly licensed UTF-8 text corpus stored under data/AetherMod/. The onboard index, YHWH/LORD/ADONAI name layer, section navigation, and text preview work offline. The binary does not silently embed copyrighted modern Bible translations.

RECOMMENDED CORPUS LAYOUT
bookname.txt -> one UTF-8 text file per book
Optional: verses.txt or a licensed structured corpus for chapter/verse search.
